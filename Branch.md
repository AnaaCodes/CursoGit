#A Branch é uma ramificação, onde temos um caminho paralelo onde

A Branch main: Aqui está todas as alterações efetivadas vão ficar

##Comandos: 

Criar uma ramificação: git switc -c nomeDaBranchNova ex feature/login
Trazer a branch para o main: git merge nomeDaBranch
git branch -> listas as ramificações locais
git switch nome -> troca de branch
git add . -> Add todos os arquivos alterados para Stege
